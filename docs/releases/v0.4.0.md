Lilt 0.4 is the "clay" release: more things to shape, and a lighter footprint while you're not looking.

**Download `Lilt-v0.4.0-win-x64.zip`, unzip it anywhere and run `Lilt.exe`** (Windows 11 x64; self-contained, uses the WebView2 Runtime that ships with Windows). Your tabs, bookmarks and theme from earlier builds carry over.

### New

- **Now playing.** A floating player shows what's playing in a tab you can't see (title, artist, artwork, progress) with play/pause, previous/next, seek, mute, pop-out and "go to tab". Drag it anywhere; set when it shows, its width and opacity in Customize → Media. The toolbar's music-note button (Ctrl+Shift+M) appears while something plays.
- **Visualizer.** Bars, mirrored bars or a wave, drawn from Lilt's own sound (every site, including DRM music services, via Windows 11's per-app loopback) or from the playing tab. Shows on music sites by default (the list is yours to edit), whenever sound plays, or never; toggle it with Ctrl+Shift+U, drag it anywhere, double-click to change style. It costs nothing when hidden.
- **Picture in picture and pop-out.** Alt+P pops the playing video out: into Windows' floating video window where WebView2 supports it, otherwise into a small frame inside Lilt that you drag and resize while you browse other tabs. Optional: pop videos out automatically when you switch tabs.
- **Split view.** Ctrl+Shift+S (or right-click a tab → Open in split view) shows two tabs side by side or stacked. Drag the divider, double-click it to even out; click a pane to make it the one the toolbar acts on. Restored with your session.
- **Peek.** Shift+click a link to preview it over the page; open it as a tab, in split view, or close it with Esc.
- **Command palette.** Ctrl+K: every command, open tab, bookmark, theme and layout preset and setting, found by typing a few letters.
- **Your shortcuts.** Every shortcut can be changed or removed in Customize → Keys (or the theme's `shortcuts` block). Changes work inside pages too.
- **Toolbar.** New optional buttons: split view and command palette (Customize → Layout).

### Lighter

- New **Hidden** level: when another app's window completely covers Lilt, its pages stop drawing (Chromium's background throttling) without being suspended, so coming back is instant.
- When Lilt is hidden or paused it hands its own unused memory back to Windows.
- The visualizer, the player's clock and other Lilt drawing stop whenever the window can't be seen, even while music keeps playing.
- Optional **Lean mode** (Customize → Power): Chromium's low-memory mode and one process per site.
- Smaller managed heap overhead (no background GC thread).

### Notes

- Media keys and Windows' media flyout use Chromium's hardware media key handling (on by default; Customize → Media).
- `--run "<commands>"` runs commands after start (for testing and scripting), for example `--run "split; wait 500; palette"`.
