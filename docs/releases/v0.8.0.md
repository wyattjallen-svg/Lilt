Lilt 0.8 is a performance and polish release: sleeping tabs, a view of what's using memory, more power settings, a way to start over, and a window that opens where you left it.

**Download `Lilt-v0.8.0-win-x64.zip`, unzip it over your old copy (or anywhere) and run `Lilt.exe`.** Tabs, bookmarks and settings carry over.

### Lighter

- **Sleeping tabs.** A tab you haven't looked at for an hour goes to sleep: its page closes, so it uses no memory or power at all. It stays in the list (faded) and reloads when you open it. When your PC runs short of memory, tabs unused for 5 minutes sleep early. Pinned tabs and anything playing sound never sleep. Change the time (or turn it off) in Customize → Power, put background tabs to sleep now from there or Ctrl+K, or right-click a tab → Sleep.
- **What's using memory** (Customize → Power, or Ctrl+K): each of the engine's processes, which tabs it's running and how much memory it holds, biggest first, with a Sleep button next to tabs that can sleep.
- **Solid window while you're away** (Customize → Power, off by default): Acrylic keeps blurring whatever moves behind the window; this lets it rest while efficiency mode has Lilt in the background.
- **Visualizer frame rate** (Customize → Media): 30 per second by default; lower saves power.
- **Smooth scrolling** can be turned off (Customize → Layout, after a restart) for instant, slightly lighter scrolling.
- Lilt's own memory: the .NET runtime now compacts harder before growing, and pages you can't see no longer re-check their colors while their sites rewrite themselves.

### Start over

**Customize → Privacy → Wipe everything and start fresh…** (or Ctrl+K) deletes everything Lilt keeps (tabs, workspaces, bookmarks, history, settings, extensions, cookies and sign-ins) and restarts it as a fresh install. You can keep your bookmarks or your look. To confirm, enter the four-digit code the dialog shows, on its keypad or your keyboard; Enter alone cancels. The wipe happens as Lilt restarts, before anything has its files open, and nothing in the folder that isn't Lilt's is touched.

### Easier

- **The window opens where you left it**: same size and place, maximized if it was (on a screen that's no longer there, it opens centered).
- **Recently closed** in the menu: any of the last 12 closed tabs, not just the last one.
- Right-click a tab → **Close tabs below** (or to the right, in a tab strip).
- Ctrl+K: **Mute other tabs**, **Unmute every tab**.
- **Open the tabs from last time** can be turned off (Customize → Layout) for a fresh home tab each start; the panel keeps its sites.
- Switching workspaces puts the focus on the page instead of the workspace button.
- A sleeping tab's tooltip says it's asleep.
